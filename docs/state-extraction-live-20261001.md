## 实验方法

输入复用前轮脱敏聊天、确定性风险，加上来自本地快照的订单已关联标志、无独立执行凭证及附件不可见说明。不提供人工事项、阶段、缺失项或既有候选。开发预期在请求前冻结于独立文件，仅本地核对，未发送模型。请求前预览已确认无目标标签泄漏。

输出包括focus、stage、known_information、missing_information、execution；每条需ref与对应非空连续原文quote。程序校验字段、枚举、引用存在、引文连续匹配、信息来源角色；客户接受需引用买家消息。当前实验不提供执行凭证，因此已完成及明确未完成均被拒绝，必须unknown。该约束是程序底线，不证明模型在有凭证时也能判断正确。

即使全部校验通过，仍为needs_semantic_review、semantic_verified=false、automatic_reply_allowed=false。没有将任何提取自动转成回复，原草稿及产品入口均未修改。

四份execution均为unknown，未将客服说过的登记、打款或回访升级成执行凭证；没有索要订单号，最终时点没有把账户/用药信息记为缺失。最终时点将“票据收好了”与“已交票据”区分，这是有用的边界；“票据原件是否已提交”中的原件要求并无正式政策支持，不能据此要求客户提交原件。

所有引文均通过输入内连续字符串检查和角色检查；这不证明解释完整、最新或必要。例如“医疗附件内容不可见”是内部证据访问限制，不等于客户没有提交，更不等于应重新索取。

预冻结的开发标签：focus匹配2/4，stage匹配4/4，execution匹配4/4。不要合并为模型准确率；focus枚举混合了问题类别和处理任务，本身存在歧义，两次不匹配不能全部归咎于模型。missing_information和known_information没有独立人工金标准，本轮结论为AI辅助源文复核，非真人盲评。
