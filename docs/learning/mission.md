# Mission: 从读懂客服助手到自己实现功能

## Why
项目代码由 AI 生成，用户知道需求和页面功能，但尚不清楚功能对应哪些代码、文件如何协作，以及 Python 如何产生网页。用户明确希望逐步掌握编程，最终自己实现这些功能。

## Success looks like
- 从一个页面功能找到负责显示与处理的代码。
- 解释输入如何经过函数处理并返回页面。
- 预测一个小修改的结果，亲自修改并验证。
- 逐步独立实现读取数据、判断规则与显示结果的小功能。

## Constraints
- 从本项目真实代码开始，每课只学一个小目标。
- 用具体输入、代码和输出对应讲解，逐步补充 Python 基础。
- 不把已讲过视为已掌握；通过用户练习确认。

## Out of scope
- 用户尚未指定永久排除的学习主题。
