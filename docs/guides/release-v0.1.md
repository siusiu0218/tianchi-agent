# 共情副驾 v0.1 演示版

## 启动

Python 3.11 或以上。源码包不包含比赛原始 Excel、密钥、运行数据库和虚拟环境。获得授权后，将原始 `赛题 1：数据共情者-业务数据.xlsx` 放入项目根目录，或通过 `COPILOT_DATA_PATH` 指向原文件。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

无需模型密钥即可跑通两个模板演示。需要模型时在页面填写接口、模型名和 API Key，或创建本地 `.env`，设置 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`。不要提交真实密钥。模型目前选择共情开场语，事实与建议由程序组装，未实现自由生成客服回复。

模块更新后，先在服务窗口 Ctrl+C，再重新启动。浏览器刷新不一定清除旧模块。已保存记录位于 `artifacts/copilot.sqlite3`；只编辑未确认的草稿在重启后可能丢失。备份数据库前先停止服务，不需要删除数据库重新演示。已关闭任务可在看板重新打开。

## 演示一：不适／就医

左侧导航切换“会话收件箱”和“风险看板”。会话列表支持编号选择、最近消息摘要搜索和点击切换；中间显示聊天和唯一的回复编辑框，右侧显示风险依据、订单和工单。点击回复框下方“确认并保存”展开审核表单。打开会话显示完整聊天记录，按日期分组，向上滚动查看早先消息；不再提供回放进度。“模型连接”默认收起。页面配色由 `.streamlit/config.toml` 管理，布局样式位于 `copilot/ui.py`。更新主题和代码后，重启 Streamlit 服务再查看。

1. 选择 S00268，直接查看完整聊天历史、P0 和原话依据。
2. 审核草稿，填写操作人与负责人、原因，勾选确认后保存。
3. 点击左侧“风险看板”，选择此任务，更新为处理中，再填写模拟处理结果并更新为已解决、已关闭。
4. 刷新确认任务状态与历史仍在。

## 演示二：破损／换货

1. 选择 S00001。首条买家文字“泵头是坏的”触发 P1。
2. 向上滚动查看图片消息及缺失提示。
3. 右侧工单列表仅包含最后一条聊天时间之前创建的工单；更晚的工单可在数据详情的完整快照中核对。
4. 展开物流快照：原订单中通与补发圆通分别展示。快照单号不进入回复建议，不代表已发货。
5. 确认、分派、处理、关闭。检查 S00268 不受影响。

## 复现检查

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/evaluate.py
```

评测输出 `artifacts/evaluation.json`，含固定会话清单、回放时点、数据哈希、规则与提示词版本。以会话完整历史为单位，不拆消息。全量 138 会话用于验收回归，未设置独立留出集，不能报告泛化准确率。原始工作簿变化会改变哈希，应重新冻结基线。

## 功能与限制

已实现：只读查询、风险规则与原话证据、模型开场语选择及失败回退、人工审核、SQLite 持久保存、主管分派和状态流转、物流快照隔离、缺图降级。

未实现：真实客服平台集成、角色登录和权限隔离、真实发消息／退款／换货、实际物流追踪、图片识别、独立标注评测及业务收益验证。操作人姓名为手工记录，审计日志不等于具备防篡改能力。P0 是项目人工处理优先级，不是医学严重程度或诊断。
