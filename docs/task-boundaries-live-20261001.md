2026-10-01。新增 `scripts/evaluate_task_boundaries_live.py`，构造6个此前未运行的合成案例，先冻结预期和提示哈希再请求。沿用上一轮任务选择提示，不为新案例修改提示。运行器支持注入input_builder，默认仍保留旧四时点输入。

新案例由同一开发过程编写，知道已发现的问题，因此只是新的合成挑战集，不是真实业务保留集或独立泛化评测。预计任务和禁止重复的问题留在本地，不发给模型。原文全为本轮编写，无新增客户隐私数据上传。
