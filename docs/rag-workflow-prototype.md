# RAG 本地审阅流程原型

检索、回复预览和逐句审阅已接成一个独立终端流程。全部使用明确标识的合成会话和本地假模型，退出后不保存；没有接入桌面、真实模型或业务系统。

## 运行与操作

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/rag_workflow_prototype.py
```

| 按键 | 行为 |
| --- | --- |
| g | 用固定片段生成待审阅预览 |
| f | 查看带结构化声明的自由文字样例 |
| e | 查看当前消息、来源原文、引用、风险和本次操作记录 |
| a | 填写核对备注，将待审阅候选采用为本地草稿 |
| r | 驳回候选，保留当前草稿 |
| d / s | 修改草稿 / 切换会话，使旧候选失效 |
| b | 展示退款、发货承诺污染被阻断的样例 |
| m | 展示规则漏检但仍需人工审核的样例 |
| u | 清空检索资料，查看无匹配时的流程 |
| q | 退出，丢弃本次内存状态 |

建议先按 f、e 核对原文和引用，再返回并按 a 填写备注；随后按 b 验证有问题的候选无法采用。切换到 SYN_B 可以检查 P0 风险仍独立保留。

## 状态与来源边界

`ReviewWorkflow` 位于 `copilot/rag_workflow_prototype.py`。生成失败保留原稿；已知错误进入 blocked；无已知错误进入 needs_human_review。采用需要匹配当前预览、非空审核者和备注，结果仅为 adopted_local_draft，不发送消息。旧稿保留在本次内存记录中。

快照包含当前会话、草稿、来源、结构化证据以及修改和生成序号。改动后再还原、切走再切回，也会使旧结果失效；较早任务不能覆盖新任务。当前聊天证据必须指向实际消息，并匹配消息时间。

来源存在和时间正确，不代表结构化声明或正文语义正确。证据字段由调用方独立核对，当前业务事件仍依赖调用方提供可信记录。规则未发现问题不等于事实获批；隐含到账措辞等已知漏检仍保留在演示中。固定片段引用与自由文字逐句声明分别展示。

审核者名称只是演示标记，没有身份认证或持久审计；当前状态机用于单进程顺序调用，未验证多线程共享安全。本轮脚本模拟确认只是路径验收，不代表真人完成业务审核。
