# 共情副驾：第一版使用指南

## 现在能做什么

1. 按会话查询比赛 Excel 中的聊天、关联订单与工单；ID 保留为字符串。
2. 根据买家原话给出 P0 / P1 / 待核实提醒，并显示原始消息证据。
3. 无模型时给出明确标识的本地模板；配置兼容 Chat Completions 的模型后，可调用模型选择共情措辞，程序填入确定的事实和行动建议。

这是固定顺序的最小 Agent 工作流。数据适配器、规则和模型连接分别独立，后续可替换。当前模型模式是受约束的回复组装，不是自由生成长回答。模型不能降低规则优先级，也没有写工单、退款或对外发送工具。

## 启动

在项目根目录的 PowerShell 中执行：

```powershell
python -m pip install -r requirements.txt
.\run.ps1
```

如本机策略不允许脚本，直接执行：

```powershell
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

访问 http://127.0.0.1:8501 。默认案例是 S00268，拖动左侧回放进度可查看更多消息。

## 模型配置

展开“使用大模型辅助措辞”，填写接口地址、模型名、密钥，再点击调用按钮。也可将 `.env.example` 复制为 `.env` 后填写。密钥不进入版本库。没有配置时，数据查询和规则提醒仍正常运行。

- 接口地址填写服务方的 API 根地址（通常含 `/v1`），程序追加 `/chat/completions`。
- 服务需支持 `response_format: {"type":"json_object"}`。
- 本地兼容服务可填写 `http://127.0.0.1:端口/v1`，不必填密钥。
- 只有点击按钮才发送请求。发送预览列出全部业务输入：买家文字（连续长数字和邮箱做基础替换）、规则等级、候选措辞；不发送整本表格、订单字段或工单字段。基础替换不等于彻底匿名化，请检查预览。
- 超时、错误格式、非法字段或违反 P0 措辞限制时，明确提示失败并保留本地模板；不会冒充模型成功。
- 即使模型返回成功，草稿仍需客服审阅，不自动发送。

## 第一个固定案例与时间边界

| 项目 | 固定值 |
| --- | --- |
| 会话 | S00268 |
| 回放时点 | 2026-05-15 13:12:43 |
| 可见买家消息 | 39881346881031.PNM |
| 关联订单 | [示例订单号已隐藏] |
| 预期提醒 | P0，引用上述买家消息 |
| 已创建工单 | 0 张；BLFY41232690 的表中创建时间是 13:46:43 |
| 动作状态 | draft_only，无外部执行 |

聊天中的工单说法与工单表时间存在差异；不反推、不补造状态。工单“数据快照”单独供人工浏览，绝不输入回放 Agent。订单商品、数量、下单时间视为购买时固定字段，这是本版明确假设；订单状态、金额结算、物流、工单症状和处理状态没有变更历史，不用于历史回放。

`scene_major`、`scene_minor`、`is_target_buyer_message` 等标签不进入 Agent。图片不参与识别，出现图片消息会明确提示未查看。

## 验证与复现

```powershell
$env:PYTHONUTF8 = '1'
python -m unittest discover -s tests -v
python -m copilot --session S00268
```

测试覆盖固定案例、未来工单排除、标签排除、ID、买家/客服角色、基础否定句、模型接口参数及失败回退、页面切换与回放。工作簿缺失时会跳过本地数据测试。运行前后比对原始工作簿 SHA-256。

规则只是保守原型，不是医学分级或已验证的风险分类器。否定、假设、复杂多轮语义仍可能误判；“待核实”不等于安全。尚未完成固定训练/评测切分和总体风险召回率评估。用户已验证基础模型调用成功；本地审核持久保存及主管看板已实现。

## 第二个案例：S00001 破损换货

重启服务后选择 S00001：首条消息显示 P1；拖动到第 3 条可看到缺失图片提示。左侧“补充回放时点”选 2026-05-05 10:29:45，才可确认表中换货工单已创建。聊天中的更早说法不覆盖工单创建时间。

“物流／换货核实”分开显示历史回放可知信息和只供人工浏览的物流快照。原订单是中通、补发是圆通；快照单号不证明历史时点已经发货，不能加入回放草稿。缺少图片时继续核实文字和工单，不声称识别了图片。

审核确认后，在页面底部看板选择 S00001，分派负责人并依次推进处理中、已解决、已关闭。填写的说明和状态都是本地模拟处理记录；不会影响 S00268，也不会执行真实换货、退款或发消息。

更新模块后如遇 ImportError，停止旧服务（Ctrl+C）并重新启动：`.\.venv\Scripts\python.exe -m streamlit run app.py`。重启保留已保存的数据库记录，但未保存草稿可能丢失。
